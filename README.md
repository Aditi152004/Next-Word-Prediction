This project is a Deep Learning-based Next Word Prediction System that predicts the most probable next word given an input sequence of three words. The model is trained using Natural Language Processing (NLP) techniques and a stacked LSTM architecture to learn contextual relationships between words from a text corpus.

The project demonstrates the complete NLP pipeline—from text preprocessing and tokenization to sequence generation, model training, and real-time next-word prediction.

Features:             
Text preprocessing and cleaning                 
Tokenization using TensorFlow/Keras Tokenizer                                    
Automatic vocabulary generation                      
Sequence generation using sliding window technique                      
Multi-layer LSTM architecture for context learning                         
Real-time next word prediction
Model checkpointing during training
Saved tokenizer for inference

Tech Stack:

TensorFlow
Keras
NumPy
